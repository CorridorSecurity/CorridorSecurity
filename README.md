# Corridor

Corridor is the Security Layer for AI Coding.

Learn more at https://corridor.dev, and get started by going to https://app.corridor.dev.

## MDM provisioning

This repository hosts [MDM provisioning scripts](mdm/README.md) for deploying the Corridor extension, CLI, and agent plugins to managed devices. Supported MDMs: Microsoft Intune (macOS and Windows), Kandji, Jamf Pro, and Fleet (macOS).
